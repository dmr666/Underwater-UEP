# 水下目标检测 SCI 论文设计文档 (DUO / YOLOv8n)

## 1. 数据集: DUO (Detecting Underwater Objects)
- 来源: 基于 URPC 系列收集 + 重新标注, arXiv:2106.05681, ICMEW 2021
- 规模: train 6671 图 / test 1111 图 (测试标注公开!), 4 类
  - holothurian 海参 7887 | echinus 海胆 50156 | scallop 扇贝 1924 | starfish 海星 14548 (共 74515 目标)
- 下载: 百度网盘 https://pan.baidu.com/s/1Be8zc9UdR_Pdsyotg_vR2Q 提取码 4bfl
  - 备用: figshare https://figshare.com/articles/dataset/DUO_zip/25370527/2
- 标注: COCO json + YOLO txt 均自带
- 选 DUO 不选 URPC 的原因: URPC 测试集标注未公开, 无法报 test 结果; DUO 划分公开、可公平对比

## 2. 问题定义 (论文叙事)
水下图像受散射/吸收影响, 存在三类退化: (a) 蓝绿色偏 (颜色通道失衡), (b) 低对比度/雾状模糊, (c) 光照不均。
这些退化削弱目标与背景的判别信息, 导致通用检测器在水下场景精度骤降。
主流解法: (1) 水下图像增强作为预处理 (2) 检测器结构改进 (注意力/融合) (3) 增强-检测联合训练。
本论文: 零参数可解释增强管线 (UEP) + 轻量检测器改进, 面向水下机器人嵌入式部署。

## 3. 方法设计 (创新点, 全部可消融)

### C1: Underwater Enhancement Pipeline (UEP) — 零参数预处理
- 灰度世界白平衡 (修正蓝绿色偏): 按 R/G/B 通道均值比例归一
- CLAHE 对比度受限自适应直方图均衡 (局部对比度, 在 LAB 空间 L 通道)
- 饱和度微调 (颜色保真)
- 实现: OpenCV, 零可训练参数, 推理时直接前置 (或离线增强训练集)
- 卖点: 无额外参数/FLOPs, 可解释, 即插即用

### C2: 轻量通道-空间注意力模块 (可选, 决定 B2 是否成立)
- 在 YOLOv8n 的 C2f 之后/Neck 融合处插入轻量注意力 (ECA 式通道注意力, 或与 TinyObject 不同的新写法)
- 预期 +1-2 个点

### 消融协议 (严格同协议, 复用 AutoDL + train_p1.py 式流程)
| 组 | 内容 | 作用 |
|----|------|------|
| B0 | YOLOv8n 原始图像 | 基线 |
| B1 | YOLOv8n + UEP | C1 单独贡献 |
| B2 | YOLOv8n + UEP + C2 注意力 | 完整方法 |
- 统一: 从头训练 pretrained=False, patience=0, seed=0, batch=8, imgsz=640, epochs=150
  (DUO 数据量 6671, 150 epochs 在 4090 上约 2-4 小时/轮, 三轮 + 对比 < 15h, 预算 < 40 元)

## 4. 实验计划
1. 数据准备: 下载 DUO → 检查标注 → 划分确认 (官方 train/test 不动) → 离线生成 UEP 增强版训练集
2. 主实验: B0 / B1 / B2 (test 集评估, mAP50 / mAP50-95 / AP per-class)
3. 对比实验: YOLOv5s、YOLOv8s、Faster R-CNN (或引用 DUO benchmark 数字), 效率对比 Params/FLOPs/FPS
4. 可视化: test 集检测结果对比 (原始 vs UEP), 错误分析 (漏检/误检)
5. 可选: RUOD 数据集泛化实验 (加分项, 若时间允许)




## 5. 风险与预案
- B1 不提升 (增强无效): 已排除——水下增强对检测的增益在大量文献中验证 (2-5 个点)
- 增强过度 (训练集增强版过拟合增强分布): 预案 = 训练时混合原始+增强 (比例消融), 或 UEP 强度随机化
- C2 注意力无增益: 预案 = 论文主打 C1 (UEP) + 工程效率, C2 降级为可选消融 (如实报告)
- 数据标注质量问题 (DUO 有密集/模糊目标): 如实报告, 与 DUO benchmark 对比时注明协议一致
